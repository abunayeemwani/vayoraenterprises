# AQUAYN by Vayora Enterprises (Pure HTML, CSS, JS Edition)

This is the pure, standalone vanilla frontend implementation of the master website for **AQUAYN by Vayora Enterprises** (Shopian, Jammu & Kashmir).

No Node.js, npm, bundlers, or frameworks required! Just double click `index.html` or host it on any static web server (GitHub Pages, Netlify, Vercel, Apache, Nginx).

---

## 📁 File Structure

```
aquayn-html-css-js/
├── index.html        # Complete semantic HTML5 structure with all pages & modal
├── style.css         # Complete master design system, color tokens, and responsive layouts
├── script.js         # Single-page navigation router, vector PET visualizer, & estimator logic
├── favicon.svg       # Brand icon
└── README.md         # Deployment & hosting instructions
```

---

## 🌟 Highlights
1. **Zero Dependencies**: Pure HTML5, Vanilla CSS3, and modern ES6 JavaScript.
2. **Interactive PET Bottle Engine**: Renders crisp scalable vectors of 1L and 500mL bottles with realistic lighting, specular gloss streaks, and mouse tilt tracking.
3. **Multi-Page Routing**: Seamless client-side navigation between Home, Our Brand, Our Product, Distribution, Quality, Contact, Privacy Policy, and Terms.
4. **B2B Wholesale Estimator**: Real-time pallet, cargo weight, and bottle count calculation tool.
5. **Trade Lead Modal**: Validates inputs (name, business name, phone, district) and formats an instant trade docket copyable to clipboard.
